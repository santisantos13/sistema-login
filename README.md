# Tela de Login e Cadastro - NexPlay

Exercício de HTML e CSS: telas de login e cadastro da loja fictícia **NexPlay**.

> Projeto de estudo. É apenas front-end: os formulários não enviam dados para nenhum servidor.

## O que tem aqui

- `index.html`: tela de entrada (e-mail e senha)
- `cadastro.html`: tela de cadastro (nome, e-mail e senha)
- `home.html`: página inicial da loja, com campo de busca e acesso à conta
- `style.css`: estilos compartilhados pelas páginas
- `Imagens/`: imagens usadas nas páginas

## O que pratiquei

- Estrutura semântica com `header`, `main`, `section` e `footer`
- Formulários com `label`, `input` e validação nativa (`required`, `type="email"`)
- Variáveis CSS (`:root`) para a paleta de cores
- Transições (`hover`, `focus`) e animação com `@keyframes`
- Publicação do site com GitHub Pages

## Como ver o projeto

O site está publicado em `[santisantos13.github.io](https://santisantos13.github.io/sistema-login/)`

Ou, localmente:

1. Baixe ou clone este repositório
2. Abra o arquivo `index.html` no navegador
